# Prompt Optimizer Skill

Optimize and refine prompts to maximize LLM accuracy, structure, and quality.

## Capabilities
1. **System Prompt Optimization**:
   - Establish crystal-clear persona and operating principles.
   - Inject input-output boundaries and few-shot exemplary outputs.
   - Remove ambiguous phrases, enforce explicit constraints and edge case handling.
2. **User Prompt Optimization**:
   - Structure task descriptions into Objective, Context, Constraints, and Expected Output.
   - Use variable slots (e.g., `{{variable}}`) for parameterized generation.
3. **Iterative Critique & Refinement**:
   - Compare baseline output against target requirements.
   - Apply structured critiques: surface weak assumptions, evidence gaps, and actionable changes.
