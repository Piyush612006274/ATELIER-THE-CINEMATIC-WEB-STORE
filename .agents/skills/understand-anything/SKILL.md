# Understand Anything

AI-powered codebase understanding suite to analyze, visualize, and explain any codebase.

## Available Commands:
- `/understand` — Analyze codebase and produce interactive architecture graph
- `/understand-dashboard` — Interactive web dashboard for exploring architecture
- `/understand-explain` — Deep-dive explanations of modules, architecture, and concepts
- `/understand-onboard` — Step-by-step developer onboarding guide
- `/understand-diff` — Architectural impact analysis for pull requests and git diffs
- `/understand-domain` — Extract domain model and business workflows
- `/understand-chat` — Architecture-aware Q&A bot
- `/understand-figma` — Design-to-code alignment and UI audit
- `/understand-knowledge` — Merge documentation and knowledge bases into the graph
